# Contributing

statusbar does not accept pull requests.

To report a specific bug or request a specific feature, open an issue. Describe
the problem or use case clearly enough to evaluate it.

For bugs, include the statusbar version, operating system, terminal, shell, exact
steps to reproduce the problem, expected behavior, and actual behavior. For
features, describe the concrete workflow or limitation the feature would
address.

Issues are the place for discussion and prioritization. Implementation remains
with the project maintainer.
